# Shipping Mode Escalation Policy

## Purpose
Historical performance data shows late-delivery risk varies dramatically
by shipping mode, with First Class and Second Class shipments showing
substantially higher late-risk rates than Standard Class. This policy
defines mode-specific escalation actions.

## First Class Shipments
First Class shipments carry the tightest promised delivery window and
the highest historical late-risk rate of any shipping mode. Any First
Class shipment flagged as High or Very High risk should be treated as a
top operational priority. Case owners should:
- Confirm with the carrier within 2 hours whether the promised 1-day
  window is still achievable.
- If not achievable, consider a proactive courtesy credit for the
  customer, since First Class customers have paid a premium for speed
  and a missed promise carries higher reputational cost than a Standard
  Class delay.
- Where feasible, transfer the shipment to a carrier with better
  same-day/next-day performance in that origin-destination lane.

## Second Class Shipments
Second Class shipments should follow the same case-ownership rules as
First Class but with a 4-hour (rather than 2-hour) initial response
window, reflecting the slightly longer promised delivery window and
correspondingly lower — though still elevated — late-risk rate.

## Standard Class Shipments
Standard Class has the lowest historical late-risk rate and the most
slack in its promised delivery window. Standard Class shipments should
only be escalated to individual case review if they are flagged Very
High risk, or if tracking data shows an active delay. Routine Moderate
or High risk scores on Standard Class shipments are usually driven by
secondary factors (order status, geography) rather than the shipping
commitment itself, and should be monitored via the automated dashboard
rather than manually reviewed.

## Same Day Shipments
Same Day shipments should be escalated immediately regardless of
predicted risk level, since any delay on a same-day promise is
immediately visible to the customer and cannot be corrected within the
promised window once missed. Treat any Same Day shipment scored above
Low risk as requiring active monitoring for the remainder of the day.

## Structural Note for Leadership
Because First Class and Second Class shipments show late-risk rates far
above Standard Class (historically over 75-95% vs under 40%), this is
not primarily a shipment-level operational problem but a promised-window
design problem. Operations leadership should periodically review whether
the promised delivery windows for expedited modes are realistic given
current carrier and warehouse capacity, rather than relying solely on
case-by-case intervention.
